The model

Real, fine-tuned Vision Transformers pulled live from HuggingFace Hub — no placeholder, no random head. This section walks through the ensemble, its preprocessing, and the explainability method we use on top of it.

    Cross-Checkpoint Ensemble Refinement (CCER)

    Each individual checkpoint caps at ~73% validation accuracy and is badly biased — Kontawat over-calls "Mild NPDR" on healthy retinas, rafalosa under-calls disease. We stack four well-known, training-free techniques to fix this:

    ⚖️

    Model ensemble (CCER)

    Each member's labels are remapped to the unified ICDR scale, then probabilities are averaged with equal weights. Their errors are anti-correlated, so the ensemble beats either alone.

    🔄

    Test-time augmentation

    Retinal diagnosis is horizontal-flip invariant. We forward both the original and the mirrored image and average the predictions.

    ⭕

    Circular fundus crop

    Auto-crop the retinal disk (luminance threshold τ = 15) out of any black border before inference so the model doesn't waste attention on padding.

    🎛️

    Ben Graham preprocessing

    Subtract a Gaussian-blurred copy (σ = 10) to normalize local illumination — the 2015 Kaggle DR winner's transform. The raw and Ben Graham paths are mixed with α = 0.65.

    Net effect on the curated Wikimedia gallery: baseline 1/4 → ensemble 3/4 top-1 correct on the four-image baseline-overlap subset, and the CMV-retinitis image (out-of-distribution) is correctly rejected as non-DR.

    Ensemble members

    • Backbone: ViT-B/16 (ImageNet-21k pretrained), fine-tuned for DR severity by each checkpoint's author
    • Member 1 (primary): rafalosa — weight 1.0, used for the attention overlay
    • Member 2: Kontawat — weight 1.0
    • Task: 5-class single-label severity grading (ICDR scale)
    • Label remap: each checkpoint's id2label is mapped onto severity 0–4
    • Framework: HuggingFace Transformers + PyTorch (MPS / CUDA / CPU)

    Explainability — Attention Rollout

    Grad-CAM doesn't naturally fit a ViT. Instead we use Attention Rollout: average attention across heads, add a residual to the attention matrix, and multiply the per-layer matrices together from input to output. The CLS-token row of the final rollout gives a per-patch importance score, reshaped to 14×14 and upsampled to 224×224 for the overlay you see in the Predict tab.

    Why a Transformer for retinas?

    Retinal lesions (microaneurysms, hemorrhages, cotton-wool spots) are often small, sparse, and spatially distributed. Self-attention lets every patch "see" every other patch from layer 1, so the model can correlate subtle lesions across the whole fundus instead of building up the receptive field layer by layer like a CNN.

    Disease types

    This classifier targets the 5-point International Clinical Diabetic Retinopathy severity scale, the same scale used in clinical screening programs and the APTOS 2019 Kaggle challenge.

    Bonus — multi-disease pipeline (RFMiD)

    The repository also ships a full ResNet50 + two-stage fine-tuning pipeline for the Retinal Fundus Multi-Disease Image Dataset (RFMiD) — a 3,200-image multi-label dataset covering 45 retinal conditions:

    Confusion-matrix interpretation guide

    DR severity is ordinal — confusing Mild ↔ Moderate is very different from confusing No DR ↔ Proliferative DR. When you benchmark this model, look at:

    • Referable DR detection — binary task: ≥ Moderate vs < Moderate. This is what screening programs care about.
    • Quadratic weighted κ — penalizes far-off misgradings more than close ones; standard APTOS metric.
    • Macro recall — guards against under-calling rare severe cases.

    About the project

    End-to-end M.Tech project for diabetic retinopathy grading. The goal was a real, explainable, deployable diagnosis pipeline built on top of modern pretrained medical-imaging models — not a toy demo.

    1

    Model sourcing

    Two ViT-B/16 checkpoints fine-tuned for DR severity grading are pulled live from HuggingFace Hub (model card) behind a checkpoint-agnostic service abstraction.

    2

    Preprocessing

    Circular crop, then two paths — raw and Ben Graham (σ = 10) — each with horizontal-flip test-time augmentation.

    3

    Inference

    Eight ViT forward passes (2 members × 2 views × 2 paths); per-member probabilities are remapped to the ICDR scale and combined by CCER.

    4

    Explainability

    Attention Rollout across all 12 layers produces a 14×14 saliency map that is upsampled and overlaid on the original fundus — so a clinician can verify why the model is confident.

    5

    Deployment

    FastAPI backend + static HTML/CSS/JS frontend. No build step, no framework lock-in, easy to containerize and deploy behind nginx.
